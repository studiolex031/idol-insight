# Contributing

1. Keep the app offline-first and dependency-free. Do not add trackers, ads, Google Play Services, proprietary SDKs, remote executable code, or runtime downloads.
2. Run `./gradlew clean assembleRelease`; for web logic, run the upstream Node tests when available.
3. Every factual claim must retain a source URL and verification date. Clearly separate verified facts, editorial analysis, anecdotes, and fictional scenarios.
4. Do not commit credentials, keystores, build outputs, copied programme media, lyrics, transcripts, substantial quotations, or third-party artwork.
5. Contributions to code/text are accepted under GPL-3.0-or-later; contributions to original artwork/store graphics are accepted under CC BY-SA 4.0. State any third-party provenance explicitly.
6. Preserve the non-affiliation disclaimer and accessibility/reduced-motion behaviour.
