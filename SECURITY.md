# Security policy

Report a vulnerability privately to the repository owner through the security contact published on the eventual public repository. Until that repository exists, do not disclose sensitive details in a public issue.

Supported version: 1.0.x. The app has no backend, account system, analytics, ads, Internet permission, or dynamic code loading. Reports involving WebView navigation escapes, local-file access, JavaScript bridges, unsafe intent handling, or bundled-content integrity are in scope. Never include passwords, personal data, or signing keys in a report.
